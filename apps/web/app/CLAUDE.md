# apps/web/app — routes and app shell

## Purpose

React Router v7 app directory: route config, root document, global providers and the page/layout files for every URL.
Parent: `../CLAUDE.md`.

## Key files

- `routes.ts` — entry: merges `routes/core.ts` + `routes/extended.ts` via `routes/helper.ts#mergeRoutes`, wraps all in `layout.tsx`, adds `*` -> `not-found.tsx`
- `routes/core.ts` — every route, written by hand (~400 lines). Folder names are NOT auto-routed.
- `routes/extended.ts` — empty `extendedRoutes`; extension point (extended wins over core on same file)
- `routes/redirects/` — legacy URL redirects (e.g. `analytics` -> `analytics/overview/`, `sign-in`, `inbox`)
- `root.tsx` — HTML shell, kept thin; `layout.tsx` — pathless app shell; `provider.tsx` — Store, Translation, Toast, SWR, Instance/Store wrappers
- `entry.client.tsx`, `error/` (dev/prod error screens), `not-found.tsx`
- `compat/next/` — shims for `next/link`, `next/navigation`, `next/script`, `next/image` (aliased in `vite.config.ts`)
- `assets/` — images/fonts/empty-state art (no code); `types/` — d.ts for next shims
- `(home)/` — sign-in page at `/`
- `(all)/` — sign-up, accounts/\*, onboarding, invitations, create-workspace, `settings/profile/`
- `(all)/[workspaceSlug]/(projects)/` — workspace app: home `page.tsx`, `sidebar.tsx`, `header.tsx`, and
  - `profile/[userId]/` — "Your work" (summary, `[profileViewId]` = assigned/created/subscribed, `activity/`)
  - `analytics/[tabId]/` — Analytics (`overview`, `work-items`)
  - `active-cycles/`, `browse/[workItem]/`, `drafts/`, `notifications/`, `stickies/`, `workspace-views/`
  - `projects/(list)/` and `projects/(detail)/[projectId]/` — issues, cycles, modules, views, pages, intake, archives
- `(all)/[workspaceSlug]/(settings)/settings/` — workspace + project settings

## Rules for this folder

- Adding a page = create `page.tsx` (+ `layout.tsx`) AND register it in `routes/core.ts`. For Neuric-only routes prefer `routes/extended.ts` to keep upstream merges clean.
- `(group)` folders are pathless groups; `[param]` folders map to `:param` in core.ts.
- Pages stay thin: header + `PageHead` + a component from `@/components/...`. Logic goes in components/stores.
- Type route props with `import type { Route } from "./+types/page"` (generated by `react-router typegen`).
- Auth: workspace routes are wrapped by `AuthenticationWrapper` (`@/lib/wrappers`) and `WorkspaceAuthWrapper` / `ProjectAuthWrapper` (`@/layouts/auth-layout`).
- Use `next/link` / `next/navigation` imports only via the compat shims (existing pattern).

## Depends on / used by

- Uses: `@/components`, `@/hooks/store`, `@/layouts`, `@/lib`, `@plane/i18n`, `@plane/blocks`.
- Used by: React Router / Vite build (`react-router.config.ts`).

## How to test

`pnpm turbo run check:types --filter=web` (regenerates `+types`), then open the route in `pnpm dev`.
