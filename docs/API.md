# API changes (ours)

Every new or changed endpoint: method, path, permission, request, response, errors. Follow Plane's existing API docs style.

| Method | Path                                                                       | Permission                                                          | Purpose                                                                                                                                                                                 |
| ------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST   | /api/workspaces/{slug}/projects/                                           | Workspace admin/member                                              | Accepts `target_date` (YYYY-MM-DD, nullable). `prd_page` is rejected on create (400).                                                                                                   |
| PATCH  | /api/workspaces/{slug}/projects/{pk}/                                      | Workspace admin or project admin                                    | Accepts `target_date` and `prd_page` (must be a public, non-archived page linked to this project; `null` clears). Invalid values give 400 `{"prd_page": ...}` / `{"target_date": ...}`. |
| GET    | /api/workspaces/{slug}/projects/ and /api/workspaces/{slug}/projects/{pk}/ | Workspace admin/member/guest                                        | List and retrieve return `target_date` and `prd_page` (page id or null).                                                                                                                |
| POST   | /api/v1/workspaces/{slug}/projects/                                        | API key, workspace admin/member                                     | Accepts `target_date`.                                                                                                                                                                  |
| PATCH  | /api/v1/workspaces/{slug}/projects/{pk}/                                   | API key, project admin (or workspace admin who is a project member) | Accepts `target_date` and `prd_page` (same rules as the web-app PATCH; 400 `{"prd_page": [...]}` on an invalid page).                                                                   |
